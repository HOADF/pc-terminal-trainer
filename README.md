# PC Terminal Trainer

Интерактивный тренажёр-справочник команд Windows (CMD). Вводите команду —
получаете приблизительный пример результата, как в настоящем терминале.
Если не знаете команду или ошиблись — появится подсказка с ближайшим
совпадением.

Демо: https://hoadf.github.io/pc-terminal-trainer/

## Что умеет

- ~35 команд CMD по категориям: файлы и папки, система, сеть, прочее.
- Автодополнение по Tab и подсказки-чипы по мере набора.
- История команд (стрелки вверх/вниз).
- Боковой справочник со всеми командами — клик подставляет пример в строку ввода.
- Адаптивная вёрстка, на мобильных справочник открывается по кнопке.

## Важно

Это обучающая симуляция. Ничего не выполняется на настоящем компьютере —
вывод команд заранее подготовлен как типичный пример для каждой команды.

Чистые HTML5 / CSS3 / JavaScript, без фреймворков и сборщиков.
